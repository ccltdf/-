# 盘前预测 · 1 日 / 2 日走势

用 T 日 9:00 之前的数据（A 股 T−1 收盘 + 隔夜美股 + 日韩），预测 A 股「今天」和「明天」的走势。
包含数据抓取、信号体检、两个提前量的预测器，以及每日一键入口。

## 文件

| 文件 | 作用 |
|---|---|
| `fetch_data.py` | 抓取 54 个协变量的日线（2018 至今），按「T 日 9:00 前可知」规则对齐成面板 |
| `signal_check.py` | 体检这些协变量对 A 股的预测力（IC / 方向准确率 / 扣成本后收益） |
| `predict.py` | 两个提前量的预测器：h1（1 个交易日后）、h2（2 个交易日后）、h2c（两日累计） |
| `daily.py` | **每天跑的入口**：更新数据 → 出今日/明日预测 → 记台账 |
| `fetch_universe.py` | 抓模块一候选池（464 只取前 200）的日线，供横截面/个股分析用 |
| `data/universe/<代码>.csv` | 候选池个股日线（后复权，2018 至今） |
| `data/raw/<key>.csv` | 每个标的的原始日线 |
| `data/panel.csv` | 面板：2139 个 A 股交易日 × 55 列协变量 |
| `data/targets.csv` | 当日真实收益（标签，决策时不可用） |
| `data/forecast.csv` | 逐日滚动预测序列（pred_h1 / pred_h2 / pred_h2c 与真实值对照） |
| `data/model.pkl` | 最终 h1 / h2 模型（含特征名与最新预测） |
| `data/_report.txt` `data/_signal_check.txt` `data/_predict.txt` | 三次运行的报告 |


## 候选池个股日线（模块一 → 这里）

```bash
D:\anaconda3\python.exe fetch_universe.py              # 前 200 只
D:\anaconda3\python.exe fetch_universe.py --top 464    # 全部 464 只
D:\anaconda3\python.exe fetch_universe.py --list       # 只看池子不抓
```

候选池读 `llm_web_ask/output/stocks.xlsx` 的「共识」sheet：deepseek 657 + 豆包 280 + 元宝 200，
合并去重后 464 只，已按「出现平台数降序、平均序号升序」排名。前 200 名 = 109 只三平台共识 + 91 只双平台。

**复权用后复权（默认 `--fqt 2`），不是前复权。** 东财的前复权是减法调整，高分红股早期价格会被减成负数
（陕煤 601225 有 406 行负价、兖矿 600188 有 727 行负价），收益率没法算。后复权是乘法调整，无负价，
收益率与真实持有收益一致；代价是价格绝对值被放大（茅台显示 8399 而非 1350），做因子/回测无影响。
要真实成交价用 `--fqt 0`。

输出 `data/universe/`：每只一个 CSV（date/open/high/low/close/volume/amount/振幅/涨跌幅/涨跌额/换手率）、
`_index.csv` 清单（含补全的股票名称）、`_report.txt` 报告、`_data_issues.txt` 数据提示。
200 只约 36 秒（并发 4）。

## 完整流水线（模块一 → 模块二 → 明日走势）

```bash
D:\anaconda3\python.exe pipeline.py                 # 默认 200 → 15 → 5，约 2.6 分钟
D:\anaconda3\python.exe pipeline.py --quick-only    # 只跑粗筛，约 20 秒
D:\anaconda3\python.exe pipeline.py --final 3 --prescreen 10
```

链路：AI 共识池 200 只 → 抓日线 → **两级漏斗** → 输出推荐组合 + 个股 + 明日走势。

三级漏斗是为了跑得动：完整模块二每只 9~18 秒（8 折 × 10 轮重训），200 只要 40 分钟以上。
而模块二里真正慢的只有 TCN+Transformer，六条件/PS/回测都是毫秒级。所以先用 Ridge 顶替预测器
把 200 只过一遍（每只约 0.08 秒），再让 15 只跑真正的深度模型。粗筛与精评共用同一套信号与回测代码。

输出 `output/`：`pipeline_report.md`（可读报告）、`recommendations.csv`（结构化）、`prescreen.csv`（200 只粗筛明细）。

报告分成五段，关键是**把"买什么"和"今天买不买"彻底分开**：

| 段落 | 回答的问题 |
|---|---|
| 一、今日大盘环境 | 隔夜信息强不强，要不要打折 |
| 二、今日可执行清单 | 今天谁触发了六条件买入、建议几成仓（可能为空） |
| 三、推荐组合 | 这是**股票池**，按历史适配度排，与今天是否入场无关 |
| 四、明日走势与仓位系数 | 走势只调仓位，不否决信号 |
| 五、逐只说明 | 每只的六条件缺口、近 20 日信号轨迹、年触发频率 |

三个必须知道的口径：

1. **走势预测只调仓位，不否决信号。** 早先的版本把"六条件 Buy"和"走势强信号"做「与」，
   两个各约 56% 的弱信号相乘后触发率趋零，结果推荐出来的股票一个都不能买。
   现在六条件决定"买不买"，大盘强度只决定"买多少"（强 1.5×、中等 1.0×、弱 0.6×、反向 0.3×）。
2. **个股走势不做独立预测。** 实测个股用同一套盘前模型，方向准确率只有 50.7%（中位 50.9%、
   仅 25% 的股票能超过 52%），接近随机。所以报告里个股的明日预测是用 β 把大盘信号传导过去的
   结果，不含个股特异性 alpha。
3. **β 用 500 日算，不是 250 日。** 250 日会得到噪声：招商银行近 250 日 β=−0.01、中国神华 −0.19，
   因为银行/煤炭经常走独立行情。500 日才稳定（招行 0.30、神华 0.14）。
4. **Strategy Fitness 是这里补的。** 模块二代码里并没有实现方案定义的 Fitness 公式，
   pipeline.py 按 w1·R + w2·Sharpe + w3·(1−MDD) + w4·WinRate − Penalty 打分，
   各分项转池内百分位，权重固定不做样本内优化。

另外：粗筛（Ridge）与精评（TCN）对同一天的信号可能不一致（例如中国神华粗筛给 Buy、
精评给 Hold），因为两个预测器不同。**以精评为准**——报告里的信号全部来自 TCN。

## 每天怎么用

一条命令：

```bash
D:\anaconda3\python.exe daily.py
```

约 30 秒完成：增量更新 55 个标的（首次自动全量，约 45 秒）→ 重训 h1/h2 → 输出今日/明日预测 →
写入台账。可用参数：`--no-fetch`（离线，1 秒）、`--full`（强制全量）、`--no-eval`（跳过滚动评估）。

**建议时点：早上 8:50。** 此时美股 T−1 已收盘（北京凌晨 4~5 点）、A 股还没开盘，预测的就是「今天」。
脚本会把当天补进交易日历，所以早盘跑不会把预测目标退回到昨天；已用「删掉当天 bar」的方式验证过，
早盘与收盘后跑出的特征和预测值完全一致。

输出示例：

```
数据：55 个标的  最新 A股 2026-10-29 / 美股 2026-10-28  （用时 31s）
输入：标普隔夜 +0.28%   纳指隔夜 +0.27%   A股20日波动 0.81%
----------------------------------------------------------------
预测 T 日（10-29）      +0.03%   弱信号   强度分位 17.9%
预测 T+1 日（10-30）    -0.00%   弱信号   强度分位  4.1%
两日累计               +0.03%
----------------------------------------------------------------
仓位建议：维持现有仓位，不做方向性操作
历史对照：h1 方向 56.4%（IC +0.182）｜h2 方向 50.1%（IC +0.044）
台账 1 条，暂无已实现样本
```

| 输出文件 | 内容 |
|---|---|
| `data/latest_forecast.csv` | 最新一次预测（单行） |
| `data/predictions_log.csv` | 台账：按日期累积，自动回填已实现收益与命中率 |

台账只在当天 15:05 之后才把当天算作「已实现」，盘中跑不会污染命中率统计。

## 两个提前量的实测结果


样本外滚动（2021-03 起，扩展窗口每 20 日重训），基准上证：

| 目标 | IC | 方向准确率 | 最强档准确率 | 分年度范围 | 可用性 |
|---|---|---|---|---|---|
| h1（1 日后） | +0.182 | 56.4% | 61.5% | 54.5% ~ 58.3% | 可用 |
| h2（2 日后） | +0.044 | 50.1% | 52.8% | 47.3% ~ 53.6% | 接近随机 |
| h2c（两日累计） | +0.146 | 54.0% | — | 46.0% ~ 58.7% | 不稳定，信号来自 h1 |

`predict.py` 的特征刻意只保留两个：`us_spx_ret1`（美股隔夜方向）+ `cn_vol20`（A股 20 日波动，
决定同样的隔夜信息能推动多少）。把 55 个协变量全塞进去，方向准确率反而从 56% 降到 52.8%。

## 关于收益

强信号（|预测| 前 10%）的日子胜率 65.3%，但一年只有约 98 个这样的交易日，
且单日毛收益仅 0.7% 量级——**扣掉换手成本后基本不剩**。这套预测的价值不在择时赚钱，
而在「今天该不该重仓」的仓位判断。做空需要股指期货，成本假设对结论影响极大。

## 协变量与列名

列名规则 `{key}_ret1`，值为该标的相对自身前一交易日的收益率（%）。

| 组 | key 前缀 | 内容 |
|---|---|---|
| A股大盘 | `cn_` | 上证 / 深成 / 创业板 / 沪深300 / 中证500 / 中证1000 / 科创50 |
| A股行业 | `ind_` | 31 个申万一级行业（映射到东财行业板块 BK 代码） |
| 美股指数 | `us_` | 道指 / 标普500 / 纳指100 |
| 美股板块 | `sec_` | 11 个 SPDR 行业 ETF（XLK/XLF/XLE/XLV/XLI/XLY/XLP/XLU/XLB/XLRE/XLC） |
| 日股 | `jp_n225` | 日经225 |
| 韩股 | `kr_ks11` | 韩国 KOSPI |
| 港股 | `hk_hsi` | 恒生指数（附加） |

数据源：东方财富公开行情接口，无需登录与 key。美股板块用 ETF 的 `secid=107.XXX`。

## 时点对齐规则

统一为「取 date < T 的最后一条收盘价」：

- A 股 → T−1 收盘
- 美股 T−1 收盘（美东）= 北京 T 日凌晨 4~5 点 → T 日 9:00 前已知
- 日经 / KOSPI T−1 收盘（北京 T−1 14:30 前后）→ 已知

**未纳入**：日韩 T 日 8:00~9:00 的盘中。这是 A 股 9:00 时真正最新的信息，但日线历史里不存在，
纳入会构成回测偏差。分钟接口实测只能回溯约 1 个月（5 分钟线 1000 根），仅够实时推理用。

## 已知限制

- 美容护理板块 2021-02 才成立（面板该列前 35.8% 为空）；科创50 自 2019-12、XLC 自 2018-06。
  建议建模时统一从 2021-03 起。
- 各市场节假日不同，`ret1` 在对方休市处会变成跨 2 日的累计收益（这是正确的，不是缺失）。
- 日线 open/high/low 仅供拆解跳空与日内使用；当日盘中抓取时 A 股最后一根是未完成 bar。
- 结论提示：这些协变量的信息几乎全部体现在**开盘跳空**上，日内走势不可预测（详见 `_signal_check.txt`）。
